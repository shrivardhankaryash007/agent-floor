# Security policy

This project is a thin, fail-closed launcher around sandbox-runtime. It reduces what an agent can read, write, and reach under its configured policy; it does not guarantee security.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting (private advisory) for this repository. Do not open a public issue for a vulnerability or publish details before a fix is coordinated.

If investigation identifies a bug in a vendor product or sandbox-runtime, report it privately to that vendor first. Do not disclose vendor findings publicly before the vendor has had a chance to respond.

## Supported versions

The supported version is the latest release.
